# Daily Fuel Log

A small static food and calorie diary starting on 9 November 2026.

## What it does

- Search a food database for a matching food or branded product.
- Choose a result, set the serving count and add its database calories to breakfast, lunch, dinner, snacks or drinks.
- Shows each day's total and an optional user-set calorie target.
- Saves entries in local browser storage, with JSON export and import for backups or another device.

## Privacy and limits

Food searches go to the Open Food Facts API. Diary entries stay in the browser and are not sent to GitHub or saved to the API. A different device or browser has a separate log until a backup is imported. Check the selected food and portion against the label. Homemade meals may need to be entered as their separate ingredients, one at a time.
