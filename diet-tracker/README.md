# Daily Fuel Log

A small static food and calorie diary starting on 9 November 2026.

## What it does

- One quick text entry for breakfast, lunch, dinner, snacks and drinks.
- Estimates calories for common foods using typical portions. The kcal field stays editable.
- Shows the total for each day and an optional user-set calorie target.
- Saves entries to local browser storage, with JSON export and import for backups or another device.

## Privacy and limits

This page is static and sends no food entries to GitHub or a server. The repository contains the app code only. Entries live in the browser profile used to open the page, so a different device or browser has a separate log until a backup is imported. Calorie figures are rough estimates: the built-in list cannot reliably infer every recipe, brand, cooking fat or serving size. Include quantities and correct the kcal value when you know it.

The Huel Black estimate is 400 kcal per 90g serving, following Huel UK's published nutrition table. Other built-in values use approximate common portions.
